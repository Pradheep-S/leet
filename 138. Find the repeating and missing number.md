# [138. Find the repeating and missing number](https://takeuforward.org/practice/dsa/find-the-repeating-and-missing-number)
```py
nums = [1,2,3,6,7,5,7]
uniq = sum(set(nums))
total = sum(nums)
neededsum = len(nums) * (len(nums)+1) // 2
repeating = total - uniq
missing = neededsum - uniq
print(repeating, missing)
