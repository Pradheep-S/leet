# [283. Move Zeroes](https://leetcode.com/problems/move-zeroes/description/)
```py
class Solution(object):
    def moveZeroes(self, nums):
        i = 0
        for j in range(len(nums)):
            if nums[j] != 0:
                nums[i], nums[j] = nums[j], nums[i]
                i+=1
        return nums
