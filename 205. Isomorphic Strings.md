# [205. Isomorphic Strings](https://leetcode.com/problems/isomorphic-strings/description/)

## Solution
```py
class Solution(object):
    def isIsomorphic(self, s, c):
        stoc = {}
        ctos = {}
        if len(s) != len(c):
            return False
        for i in range(len(s)):
            if s[i] in stoc and stoc[s[i]]!=c[i]:
                return False
            if c[i] in ctos and ctos[c[i]]!=s[i]:
                return False
            stoc[s[i]] = c[i]
            ctos[c[i]] = s[i]
        return True
