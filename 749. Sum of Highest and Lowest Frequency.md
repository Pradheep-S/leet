# [749. Sum of Highest and Lowest Frequency](https://takeuforward.org/practice/dsa/sum-of-highest-and-lowest-frequency)
## Solution

```py
def sum_highest_lowest(arr):
    freq = {}

    for x in arr:
        freq[x] = freq.get(x, 0) + 1

    highest = max(freq.values())
    lowest = min(freq.values())

    return highest + lowest
