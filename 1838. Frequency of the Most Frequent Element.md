# [1838. Frequency of the Most Frequent Element](https://leetcode.com/problems/frequency-of-the-most-frequent-element/description/)

## Solution

```py
class Solution(object):
    def maxFrequency(self, nums, k):
        nums.sort()
        l, r = 0, 0
        res, total = 0, 0
        while(r < len(nums)):
            total += nums[r]
            while nums[r]*(r-l+1) > total+k:
                total -= nums[l]
                l+=1
            res = max(res, r-l+1)
            r+=1
        return res
